# Submission packets

Built 2026-08-09 from the v1.0 PDFs published to Zenodo the same day (see
`papers/PROVENANCE.md` for the DOI table). Each folder holds everything one journal
submission needs: the compiled PDF, the LaTeX source, and a paste-ready cover letter.
The full plan (venues, fallbacks, metadata, what to expect) is `Finals/submission_pack.md`.

## Submission order

Submit in this order — Letter 3 states the companions are "under review elsewhere",
which must be true when it is sent:

1. **Paper 2** → *Experimental Mathematics* (Taylor & Francis) — `paper2_experimental_mathematics/`
2. **Paper 1** → *Mathematics Magazine* (MAA, via Taylor & Francis) — `paper1_mathematics_magazine/`
3. **Paper 3** → *Research in Number Theory* (Springer) — `paper3_research_in_number_theory/`
   — upload the two PDFs in `supplementary/` as supplementary files for the referees.

One journal per paper, one paper per journal, never simultaneously.

## Per-submission checklist

- Upload PDF + LaTeX source; paste `cover_letter.txt` into the letter field.
- Complete the portal's AI-use declaration — each paper's final "Disclosure of AI use"
  section is the reference text.
- Metadata (MSC 2020 codes, keywords) is in each paper's header and listed in
  `Finals/submission_pack.md` under "Paper metadata".
- ORCID: 0009-0007-5500-9175.
- Re-check the venue's AI policy at submission time — policies are moving.
